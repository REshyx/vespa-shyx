# vtkSHYXResampleLines

对 `vtkPolyData` 线网做三步独立处理（默认都开）：**LineMerge** 按输入 cell 顺序，从第二条 polyline 起把落在已接受折线上（或距离小于阈值）的点并上去；**Fuse** 把近点合并以保证连通；**Sample** 按弧长间距重采样。可只开其中一步。三步都关则原样输出。

LineMerge 按二叉树**两两合并**（先 (0,1)、(2,3)…，再合并这些结果），让重叠主干尽早收掉。每次合并保留左边线网；右边折线的点若到该线网的距离 ≤ **Line Merge Tolerance**（默认 1e-4×包围盒最长边），视为重叠：重叠内点丢掉，剩下的自由段作为新分支，端点吸附到前面的线上（投影在线段内部时会在该线上插入顶点）。完全落在已有线上的折线整条丢弃。

度不为 2 的顶点当作特征点保留；各分支独立 resample。间距不小于分支长度时只保留该分支两端，短分支不会被删掉。处理结束后在点数据里写 **Degree**（无向线度数：每个顶点关联的互异 `VTK_LINE` / `VTK_POLY_LINE` 边数）。纯 VTK。

参数见同目录 `SHYXResampleLines.xml`。
