# SHYX / VESPA 图标一览

本页把 `icon/` 下全部图标排成表，方便对照风格、构图和尺寸是否一致。预览统一缩放到约 72px。

约定对照：

- 菜单 PNG：目标 **128×128**、RGB（当前均无透明通道）
- fluent 变体：**512×512** PNG；qrc 里部分条目用 fluent 文件顶替同名非 fluent
- 标题栏工具：SVG，`viewBox="0 0 24 24"`
- 命名：`SHYX_<Feature>.png` / `VESPA_<Feature>.png`，空格写成 `_`

共 **67** 个图像文件（不含脚本）。
